# ОМА · версии «Клиент» и «Мастер PRO»

Сайт остался статическим (HTML + CSS + ванильный JS, без сборки и зависимостей).
Поверх каталога добавлены две версии одного сервиса, которые работают с общим
состоянием и синхронизируются между вкладками в реальном времени.

Оформление повторяет фирменный стиль oma.by: шрифт Roboto, тёмно-фиолетовая
шапка с белым логотипом (`linear-gradient(120deg, #2a1150 → #450b7b)`),
оранжевые акценты и кнопки (`#ff8400 → #f89728`), белые карточки с радиусом
10–12 px на светлом фоне `#f5f5f5`, синие ссылки `#005ead`, зелёные статусы
`#46aa42`. Все цвета и радиусы заданы переменными в начале `css/styles.css` —
палитру можно поменять в одном месте.

Переключатель версий — в шапке сайта: «Клиент» / «Мастер PRO».

## Сценарий работы

1. **Клиент** выбирает мастера (`masters.html` или блок «Мой мастер» в кабинете) —
   открывается чат с ним.
2. Клиент и мастер переписываются в чате.
3. **Мастер** собирает смету из каталога и нажимает **«Поделиться корзиной»**.
4. В чате у клиента появляется карточка **«Корзина от мастера»** с кнопкой
   **«Открыть корзину»**. Позиции добавляются в корзину клиента с пометкой,
   какой мастер её составил.
5. Клиент правит состав (количество, удаление, свои товары) — у мастера в блоке
   «Корзина клиента» правки появляются сразу, изменённые строки подсвечиваются.
6. Клиент нажимает **«Оплатить корзину»** — у мастера появляется отметка
   **✓ оплачено** (в живой корзине и в списке смет), в чат приходит системное
   сообщение.
7. После оплаты клиент выбирает **время доставки материалов** и **время приезда
   мастера** — график сразу виден мастеру.
8. Клиент заполняет **паспорт объекта**: тип и состав дома/помещений, проблему,
   бюджет и желаемые материалы.
9. Мастер видит паспорт объекта, может взять выбранный материал в нужном
   количестве или выбрать более доступную альтернативу из той же категории.

## Паспорт объекта

В кабинете клиента блок «Паспорт объекта» хранит тип объекта, состав помещений,
описание проблемы, бюджет на материалы и список выбранных товаров. В кабинете
мастера этот список отображается вместе с бюджетом: для каждой позиции доступны
кнопка «Взять этот» и варианты дешевле из той же категории. Выбранный вариант
добавляется в текущую смету мастера с количеством из паспорта.

## Как проверить синхронизацию

Откройте `client.html` и `master.html` в двух вкладках (или окнах) одного браузера
и пройдите сценарий. Работает и при открытии файлов напрямую (`file://`), и через
любой статический сервер.

Состояние хранится в `localStorage` (ключ `oma:db:v3`), между вкладками передаётся
через `BroadcastChannel` + `storage`-событие, с опросом раз в 700 мс как страховкой.
Кнопка «Сбросить демо-данные» в кабинетах очищает корзину, чат и сметы.

**Ограничение демо:** без сервера синхронизация возможна только между вкладками
одного браузера (один профиль, один origin). Для обмена между разными
устройствами или браузерами нужен backend (WebSocket/SSE + база), логику
из `js/store.js` можно перенести на сервер практически без изменений.

## Файлы

```
css/styles.css      тема oma.by: переменные палитры, шапка, каталог, карточки, подвал
css/cabinet.css     кабинеты клиента и мастера в той же стилистике
js/data.js          каталог товаров, мастера, тарифы
js/store.js         состояние, синхронизация и вся бизнес-логика
js/ui.js            шапка, подвал, переключатель версий, корзина-панель, тосты
js/app.js           каталог, карточка товара, выбор мастера
js/client.js        версия клиента
js/master.js        версия мастера
img/logo.png        белый логотип ОМА для шапки (с oma.by)
```

Данные: 1 клиент (Анна Смирнова), 4 мастера, 12 товаров — всё в `js/data.js`,
демо-данные клиента и корзины создаются автоматически при первом открытии.
